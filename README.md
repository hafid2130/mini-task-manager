# Mini Task Manager & Audit Trail System

A lightweight, full-stack task management application built with **React**, **Node.js**, **Express**, and **TypeScript**. Designed specifically to solve tracking gaps, accountability issues, and state-transition opacity within internal team workflows.

---

## 🚀 Tech Stack
- **Frontend:** React, TypeScript, Axios
- **Backend:** Node.js, Express, TypeScript, CORS
- **Persistence:** Local JSON file-based storage (`data.json`) ensuring lightweight deployment and zero external database overhead.

---

### Prerequisites
- Node.js (v16+ recommended)
- npm or yarn
